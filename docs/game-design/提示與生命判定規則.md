# MeowBox｜提示、三條生命與公平判定

版本：2026-09-23。本次即時點擊判定先適用第 1–20 關；第 21–25 關暫時仍在完整配置後結算。

## 核心原則

介面不能因為「這一步沒有立即消除」就判玩家錯誤。第 1–20 關的點擊判定不是檢查局部三連，而是用正式順序消除引擎搜尋所有後續配置；只有已證明不存在任何可清空的完整配置，才在當下扣生命。真正的消除與重力仍要等玩家放完全部托盤並按下開始才播放。

因此：

- 點到合法空格但沒有立即連線，只要仍存在可完成解，就不扣生命。
- 有多條能清空盤面的答案時，任何能完成的答案都算成功。
- 內建解答只是保證至少一條可行路線，不是唯一答案。
- 不完整配置、重複放置、點到已佔格等操作錯誤不進入結算，也不扣生命。
- 第 1–20 關若點擊後所有後續配置都已被證明無法完成，立即扣一條生命。
- 第 21–25 關暫時只有完整配置結算後仍有貓咪才扣一條生命。

## 正式狀態機

```text
editing
  ├─ 第 1–20 關合法點擊
  │    ├─ 仍有可完成解 → 保留配置
  │    └─ 已證明無解 → lives - 1，清空本次配置
  └─ 所有托盤貓已放置 + 開始
       └─ running：依規則消除、重力、下一波
            ├─ remaining = 0 → completed
            └─ remaining > 0 → lives - 1
                 ├─ lives > 0 → editing（清空本次配置）
                 └─ lives = 0 → failed（只能重開或離開）
```

扣生命後回到 `editing` 時，盤面回到原始固定盤面，托盤回到第一隻，舊配置與舊結算結果全部丟棄。這樣玩家知道下一次是在解同一題，而不是猜半盤殘局。

## 順序消除與群組判定

同款貓只要形成橫、直或兩種斜線的 3 隻以上連線，就標記為可消除格。同色且已參與連線的格子若以 8 個方向相連，合併為同一個消除群；因此交叉的橫線、直線與斜線不會被拆成多個選項。若同一波有多個群組，先比較每個群組內最小的放置數字，數字最小者先消除；原始盤面貓咪沒有放置數字時，依上到下、左到右處理平手。每次只消除一群，重力後重新計算。

## 生命規則

| 行為 | 是否扣生命 | 原因 |
| --- | --- | --- |
| 第 1–20 關點擊後仍有至少一種完整解 | 否 | 合法替代解都算正確 |
| 第 1–20 關點擊後已證明所有後續都無解 | 是，立即扣 1 | 搜尋器已檢查完整後續，不是只看有沒有立即三連 |
| 點已佔用格、重複放貓、越界 | 否 | 操作被拒絕，沒有改變狀態 |
| 托盤尚未放完按開始 | 否 | 按鈕不可用或操作被拒絕 |
| 完整配置結算後清空 | 否 | 過關 |
| 第 21–25 關完整配置結算後仍有貓 | 是，扣 1 | 本輪尚未啟用點擊即時驗證 |
| 觀看廣告 | 不改變生命 | 廣告不能把錯誤盤變成可解盤 |

每關固定 3 條生命。第 3 次失敗後只保留「重新開始本關」與「回到選關」；沒有半盤繼續、撤銷生命、延長時間或影片復原錯誤配置。

## 提示規則

每關 1 次免費提示。提示器必須從所有合法下一步中搜尋一條能導向任何已驗證可解狀態的路線；若有多個同樣安全的格子，顯示其中一個即可，但文案必須使用「建議位置」，不能說「唯一正解」。第 1–20 關的提示與點擊判定使用同一個順序消除引擎。

提示不應只檢查當下是否形成三連，也不能在搜尋器未完成驗證時把某格標成錯誤。正式上線的第 1–20 關必須在關卡驗證階段完成可解性檢查；玩家遊戲中不應看到「猜測錯誤」的生命扣除。

提示用量在扣生命重試時保留，完整重新開始本關才重置。這不影響公平性，因為提示從未替玩家直接放置貓。

## 撤銷規則

每次配置嘗試有 1 次撤銷，只能收回最新放置的托盤貓。失敗扣生命後會進入新的配置嘗試，因此撤銷次數重置為 1；重新開始本關也重置。撤銷不會移動固定貓，也不會改變生命。

## 廣告邊界

可放置的獎勵廣告只能提供不破壞答案公平性的內容，例如再次查看提示或非必要的外觀獎勵。不能用「看影片繼續」讓玩家從錯誤半盤接著玩，也不能用廣告直接免除正式失敗造成的生命扣除。
