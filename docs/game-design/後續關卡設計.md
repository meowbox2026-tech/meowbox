# MeowBox｜後續關卡設計

版本：2026-09-19。第 1–30 關已接入同一套落下引擎；以下數值與動畫規格是目前的實作基準。

## 共同方向

每一關都是「點欄落下 → 同款三連線 → 重力 → Combo」。不重新切換成拼圖或交換三消。可愛感來自貓咪的表情、落地彈性與回家時的愛心，不靠催促玩家或大量遮擋棋盤的特效。

所有關卡統一為「秒數＋消除總量＋碰頂失敗」。倒數內消除達標、結算後沒有碰頂就過關；時間到未達標或碰頂就失敗。Combo 只影響分數與效率，不另外要求指定 Combo 或指定貓種才能過關。一般遊玩不設步數上限。

第一次有效落下開始倒數；落下、消除、重力動畫、暫停、說明、廣告及切到背景時停表。零秒前已接受的落下先完整結算，仍可達標。時間歸零後不接受新的落下。同一步達標又碰頂，碰頂失敗優先。

## 關卡 2–4 的具體布局準則

- 第 2 關：同款兩隻放在中間欄底部，NOW 為同款。第一次直向消除後才恢復一般隊列。
- 第 3 關：以不同貓種作支撐，兩隻目標貓排成階梯，落下第三隻完成斜線。需確認初始支撐不已形成可消除連線。
- 第 4 關：第一輪橫線被消除，留下的貓咪因重力湊成底排三連。先以規則引擎驗證確實兩輪，不能把同時兩條線當 ×2。
- 教學只用落點虛影與短句，不強迫點唯一欄位；其他操作依然有效。

## 後續實作驗收

1. 把關卡數值抽成正式的落下模式 LevelDefinition；不要接回舊拼圖資料。
2. 所有關卡只用倒數、消除總量、碰頂三項勝負規則；新的配置先寫可重現測試。
3. 初始盤面沒有懸空貓咪或自動三連；每個教學布局都有至少一個已驗證解法。
4. 隨機隊列不得因玩家點不同欄位而偷偷更改；抽樣遊玩測試通關率及平均次數。
5. 每個新關卡都測手機、鍵盤、減少動態效果、碰頂、重玩與暫停。
6. 玩家依序完成關卡解鎖下一關；第 1–30 關都有資料、初始盤面與可玩的共同規則。

## 廣告提示與復活（所有關卡共用）

每局一次提示、一次復活，彼此獨立。玩家主動選擇觀看。只有服務回報觀看完成且獎勵種類正確才發放；取消、無填充、錯誤與未看完不扣次數，重玩重置。

### 遊戲中：看廣告提示

廣告期間停表並鎖定棋盤。完成後以星號、落點虛影和文字推薦一欄，保留到下一次有效落下。演算法先排除立刻碰頂，再比較本手消除量與堆疊高度，不改 NOW／NEXT、不消耗真實隊列亂數、不承諾必勝。動畫中、已結束、已用過或沒有安全候選時不可觀看提示廣告。

### 碰頂後：清除底部一排

完成觀看後清掉底排，其餘貓咪向下移一格、空出頂排。保留分數、消除數、NOW／NEXT 和剩餘時間；清底的貓不加分也不計消除目標。若碰頂前已達消除數，清底後可完成關卡。這是本局唯一復活，之後超時或再碰頂不能再領一次。

### 時間到：再給 3 次落下

完成觀看後改為「加賽：還有 3 次落下」，不再倒數。有效落下才扣次數，每次先完成消除和連鎖，再判定碰頂、達標及次數。最後一次仍可過關；用完未達標或碰頂則失敗，不能再復活。不清棋盤、不直接贈送消除數。

兩種復活依失敗原因提供，避免碰頂後只加步數卻沒有空位，或零秒時只清底卻無法繼續。

目前使用既有測試廣告 gateway，沒有真實曝光或營收；正式上線需接入廣告平台 SDK，驗證成功、取消、無填充、錯誤與卸載後遲到回呼。此版不加入強制插頁廣告。

## 商業化前的驗收

- 測試不移動手指的連續操作、點擊當下 NOW／NEXT 更新、快速連點不多消耗貓咪。
- 測試首次落下開表、動畫／背景／廣告停表、零秒邊界、最後一次加賽達標。
- 測試每局只領一次復活，取消與錯誤不扣次數，重玩不接收舊廣告回呼。
- 記錄無廣告過關率、超時／碰頂比例、剩餘秒數與復活成功率，再校準表中數值，不以偷偷換貓或加快倒數製造失敗。
