# 前二十五關：8×8 配置解謎

版本：2026-09-23。本文件是第 1–25 關的權威規格。第 26 關以後尚未設計，不屬於目前遊戲。

## 一局怎麼玩

1. 棋盤固定為 8×8。盤面先放好固定貓咪，托盤再依固定順序提供待放貓咪；沒有隨機補貓。
2. 配置階段只能點空格，最前面的托盤貓會放入該格。不能跳過、交換或移動已放置的貓。
3. 第 1–20 關每次合法放置後先檢查是否仍有至少一種完整解；這只是可解性判定，不會在配置階段消除或掉落。所有托盤貓放好後，玩家按「開始」才播放結算。
4. 同款貓在橫、直或兩種斜線上連續 3 隻以上，就形成一個消除群。同色且已參與連線的格子若以 8 個方向相連，合併成同一群；交叉位置只算一次。
5. 同一波同時存在多個消除群時，依群組內最小放置數字決定先後，一次只消除一群。若群組只含原始盤面貓咪，依上到下、左到右固定排序。消除後只讓失去支撐的上方連續堆疊落下，再重新判斷下一波。
6. 所有貓清空即過關；沒有倒數、頂排失敗或隨機補貓。

## 生命、錯誤與重新嘗試

- 每關開始有 3 條生命。第 1–20 關若某次合法放置已被正式順序消除引擎證明會讓所有完整配置都無法清空，當下扣除生命；21–25 暫時仍在完整配置結算失敗後扣除。
- 點到已佔格、越界或其他不合法位置只拒絕操作、不扣生命；合法但沒有立即消除、或存在另一條可行路線，都不算錯。
- 扣生命後若仍有生命，清除本次配置，回到空托盤的配置階段重新嘗試。這不是半盤接續，也不沿用錯誤配置的消除結果。
- 第 3 次錯誤後進入失敗畫面，只能重新開始本關或回到選關；不提供把錯誤盤恢復到中途的廣告按鈕。
- 每次配置嘗試有 1 次撤銷。每關有 1 次免費提示，提示用量在扣生命重試時保留，完整重新開始本關才重置。
- 只有正式結算的失敗配置會計入失敗次數；因此生命扣除與錯誤次數永遠一致。

## 卡片條件與群組數量

托盤卡片上方會顯示本關條件摘要。第 1 關的作者路線會提示直連、後續橫連與落下波數，目的是讓玩家知道要觀察什麼，不代表只能點作者指定的唯一格子。

有效連線先取格子的聯集，再以 8 向連通合併成消除群。十字或其他交叉圖形的共用格只算一次；因此「線的數量」與「實際清除格數」是兩個不同欄位，不能用每條線的 3 格相加代替。

## 公平性要求

關卡匯入前必須通過以下檢查：

1. 內建解答能清空盤面。
2. 初始盤面沒有未放貓就成立的三連。
3. 任何不合法放置都不能進入結算；合法但尚未形成消除，只要仍有完整可行路線就不算錯誤。
4. 第 1–20 關的點擊判定與正式結算使用同一個逐群順序消除引擎；扣生命後一定回到乾淨的配置狀態。
5. 第 25 關是目前最後一關，完成後不產生第 26 關。
