# MeowBox 新玩法文件

- [前二十五關配置解謎](./第一關配置解謎.md)：前二十五關共用的 8×8 棋盤、逐組消除、局部重力、難度與托盤規則。
- [遊玩規則](./遊玩規則.md)：已實作的操作、判定、分數、第一關與保存行為。
- [後續關卡設計](./後續關卡設計.md)：第 16–25 關的配置解謎設計，以及第 26–90 關的落下模式數值、貓咪名冊、動畫方向與廣告提示邊界。
- [前二十五關難度公式](./前二十五關難度公式.md)：以搜尋空間、解答緊度、連鎖深度、局部重力、方向切換與盤面密度驗證每一關的可解性與難度跳幅。
- [第 15–100 關重新設計研究](./第15至100關重新設計研究.md)：針對第 15 關後難度斷層的原因、落下／波次／Combo／四連／五連規則，以及可延伸到數百關的章節公式。
- [提示、三條生命與可見目標規則](./提示與生命判定規則.md)：完整定義 safe／dead／uncertain 判定、提示搜尋、生命回復、三連至斜線目標，以及 100 關後的內容循環。

目前實作仍是第 1–25 關配置解謎、第 26–90 關落下模式；「第 15–100 關重新設計研究」是下一階段的規則提案，尚未直接套用到遊戲。玩家完成前一關後解鎖下一關。
