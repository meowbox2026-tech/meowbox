# MeowBox 遊戲規則文件

版本：2026-09-23。這裡只描述目前可玩的第 1–25 關；第 26 關以後目前沒有關卡資料、入口或主線進度。

- [前二十五關配置解謎](./第一關配置解謎.md)：1–25 關的唯一玩法規格、生命、提示、撤銷與結算順序。
- [遊玩規則](./遊玩規則.md)：給玩家與實作者看的簡版規則。
- [後續關卡設計](./後續關卡設計.md)：16–25 關的現行設計邊界；16–20 是重新設計的過渡章。
- [前二十五關難度公式](./前二十五關難度公式.md)：可在關卡匯入前驗證可解性、難度跳幅與公平性的計算規格。
- [提示、三條生命與可見目標規則](./提示與生命判定規則.md)：定義什麼情況扣生命，以及提示如何避免誤導。
- [第 15–100 關重新設計研究](./第15至100關重新設計研究.md)：研究資料，不是目前關卡規格；26 關以後暫不實作。

## 目前唯一有效的範圍

1. 主線關卡為 1–25，所有關卡都是固定 8×8 配置解謎。
2. 玩家先依托盤順序配置，按「開始」後才進行消除與局部重力。
3. 每關 3 條生命；錯誤完整配置才扣 1 條，扣完後失敗並重新開始。
4. 失敗不能回到半盤，也沒有用廣告把錯誤盤復原的規則。
5. 第 25 關完成後回到選關，不會開啟不存在的第 26 關。
