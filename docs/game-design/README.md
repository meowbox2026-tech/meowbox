## 目前唯一有效的範圍

1. 主線關卡為 1–25，所有關卡都是固定 8×8 配置解謎。
2. 玩家依托盤順序放置；合法性只檢查座標、空格與順序，配置階段不做消除或落下。
3. 全部放置後按開始，第一組依放置順序決定；清除造成的落下連鎖必須先全部清完，再回頭處理原本存在的其他群組。
4. 沒有生命、不扣生命；配置結算失敗只重置本次配置，不保留半盤。
5. 提示的 150ms 背景搜尋只服務提示，不作放置合法性判定；超時或錯誤不拒絕合法放置。
6. 第 25 關完成後回到選關，不會開啟不存在的第 26 關。未來內容需依中央規格逐章新增至 100 關。
