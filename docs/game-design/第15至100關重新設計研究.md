# MeowBox｜第 15–100 關重新設計研究（封存）

版本：2026-09-23。狀態：研究文件，不是目前可玩的關卡規格。現行主線先收斂為第 1–25 關；第 26 關以後的舊關卡、入口與解鎖資料已移除。

## 目前結論

1. 第 1–25 關先統一使用固定 8×8 配置解謎，玩家放完全部托盤貓後才開始消除與重力。
2. 1–25 關沒有生命、不扣生命；完整配置結算失敗只清空本次配置重新解題。
3. 不保留「連鎖失敗後接著玩半盤」或「觀看影片復原錯誤盤」；重置必須丟棄錯誤配置，提示也不能改變正式結算。
4. 16–20 關先作為低分支過渡章，維持數量成長但降低同時需要預判的主線數量。
5. 26 關以後暫停，不允許從舊落下資料推導主線玩法。

## 為什麼先不把落下模式放入主線

「一次落下一隻貓 → 同時消除 → 重力 → 可能再消除」本身可以成為另一種玩法，但它需要重新定義：隊列是否可預知、死路如何證明、生命扣在哪一刻、四連與五連是否改變棋盤、提示是否能證明安全，以及廣告是否會改變答案。若這些條件未先固定，直接從第 20 關延伸會造成玩家看不懂、提示誤判和難度暴增。

因此落下模式只保留為未來研究方向，不出現在現行 1–25 關、選關、存檔或廣告流程。

## 可延伸到未來章節的研究框架

未來重新啟動 26+ 內容時，每一章最多新增一個主要變因：

| 章節步驟 | 只新增的重點 | 必須先驗證 |
| --- | --- | --- |
| A | 可預知的落下與同時消除 | 任意合法操作的結果可重播 |
| B | 四連獎勵 | 不改變三連的基本可解性 |
| C | 五連獎勵 | 不讓一次獎勵直接取代規劃 |
| D | 第二次落下或連鎖 | 每一波的停止條件明確 |
| E | 斜線或方向目標 | 目標可見且不靠猜 |

每個步驟都要有教學、練習、組合、舒緩關，不能連續堆疊新規則。若提示無法證明安全，提示只能說「暫時無法判斷」，不能把一個可能的答案說成唯一答案。

## 難度曲線研究原則

用下列指標評估關卡，而不是只看貓咪總數：

```text
D = 0.25S + 0.20W + 0.20G + 0.15R + 0.10C + 0.10M
```

- `S`：合法配置搜尋空間。
- `W`：解答需要的消除波數。
- `G`：局部重力造成的預判量。
- `R`：方向切換與路線分支。
- `C`：盤面密度。
- `M`：需要同時記住的主要機制數量。

上線前應限制相鄰關卡跳幅，並以實際失敗原因分布校正權重。玩家若常在「不知道為什麼錯」時失敗，先修提示與可見目標，不要直接增加生命消耗或廣告續接。

## 重新啟動 26+ 前的必要文件

- 一份唯一的規則規格，不得同時存在配置模式與未定義的落下模式說法。
- 每關的狀態轉移與停止條件。
- `safe`、`dead`、`uncertain` 的可測試定義。
- 至少一條作者解答與多解容許策略。
- 無生命、重置、提示、撤銷、廣告的完整流程圖。
- 自動驗證關卡沒有初始免費消除、沒有不可達目標，且相鄰難度在上限內。

在上述條件完成前，本文件只作研究筆記，不得新增第 26 關資料。
