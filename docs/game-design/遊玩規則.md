# MeowBox｜遊玩規則

版本：2026-09-23。現行主線只有第 1–25 關，全部使用配置解謎。

## 一分鐘學會

1. 看托盤最前面的貓，點棋盤空格把牠放入；不能跳過順序。
2. 全部放完後按「開始」。此時才會判斷三連、消除、重力與後續連鎖。
3. 同款貓的橫、直、兩種斜線連續 3 隻以上會消除。
4. 每關 3 條生命。完整配置結算後仍無法清空，才扣 1 條並清空本次配置重新試。
5. 生命用完就失敗；不能接著錯誤半盤遊玩，也不能用廣告復原錯誤盤。
6. 一次撤銷與一次提示是關內資源；提示不自動放置，也不宣稱只有一個答案。

## 判定順序

```text
配置全部完成
→ 按開始
→ 找三連以上的消除群
→ 依最早放置順序消除一群
→ 只讓失去支撐的上方堆疊下落
→ 再找下一群
→ 清空：過關；仍有貓：扣一條生命或進入失敗
```

## 不算錯誤的行為

配置期間點到不合適的空格不會扣生命；玩家可以用撤銷重新安排。合法但不是唯一解、或需要先整理才能消除的配置，也不能被介面直接判成錯誤。只有正式結算證明整個配置無法完成，才扣生命。

## 關卡邊界

第 25 關完成後顯示主線完成並回到選關。第 26 關以後沒有主線資料、按鈕或解鎖邏輯；未來若要增加內容，必須先另立規格與測試，不能沿用未核准的舊落下關卡。
