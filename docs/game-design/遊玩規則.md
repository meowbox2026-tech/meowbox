# MeowBox｜遊玩規則

版本：2026-09-23。現行主線只有第 1–25 關，全部使用配置解謎。

## 一分鐘學會

1. 看托盤最前面的貓，點棋盤空格把牠放入；不能跳過順序。第 1–20 關會在點擊當下檢查這一步是否仍保留至少一種完整解法。
2. 全部放完後按「開始」。此時才會實際播放三連、消除、重力與後續連鎖；配置階段不會先消除。
3. 同款貓的橫、直、兩種斜線連續 3 隻以上會消除。
4. 每關 3 條生命。第 1–20 關若點擊後已證明本關無解，當下扣 1 條；其他完整配置結算後仍無法清空，才扣 1 條。扣後都會清空本次配置重新試。
5. 生命用完就失敗；不能接著錯誤半盤遊玩，也不能用廣告復原錯誤盤。
6. 一次撤銷與一次提示是關內資源；提示不自動放置，也不宣稱只有一個答案。

## 點擊與消除判定順序

```text
第 1–20 關點擊一個合法空格
→ 搜尋所有仍可能完成的後續配置
   ├─ 至少一種可完成解 → 接受放置
   └─ 所有後續都無法完成 → 立即扣生命並清空配置
配置全部完成
→ 按開始
→ 找三連以上的消除群
→ 依最早放置順序消除一群
→ 只讓失去支撐的上方堆疊下落
→ 再找下一群
→ 清空：過關；仍有貓：扣一條生命或進入失敗
```

## 順序消除規則

同一波若有多個消除群，找出每個群組中最小的放置數字，數字最小的群組先消除。相同類型、已參與連線且以 8 個方向相連的格子視為同一群；橫線、直線與斜線交叉不拆開。消除後執行局部重力，再重新找下一波；不使用隨機順序。若群組只包含原始盤面貓咪，依固定的上到下、左到右位置順序處理。

## 不算錯誤的行為

點到已佔用格、越界或其他不合法位置時，操作被拒絕且不扣生命。合法但不是唯一解、沒有立即三連、或需要先整理才能消除的配置，也不能被介面判成錯誤。只有第 1–20 關的搜尋器已證明所有後續都無法完成時，才會在點擊當下扣生命。

第 21–25 關本輪仍沿用完整配置後結算；待下一輪完成同樣的點擊可解性驗證後再切換，不能讓兩套判定在同一關混用。

## 關卡邊界

第 25 關完成後顯示主線完成並回到選關。第 26 關以後沒有主線資料、按鈕或解鎖邏輯；未來若要增加內容，必須先另立規格與測試，不能沿用未核准的舊落下關卡。
