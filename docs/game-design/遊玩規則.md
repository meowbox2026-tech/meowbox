# MeowBox｜遊玩規則

版本：2026-09-23。現行主線只有第 1–25 關，全部使用配置解謎。

## 一分鐘學會

1. 看托盤最前面的貓，點棋盤空格把牠放入；不能跳過順序。放置只檢查座標、空格與托盤順序，不會用搜尋器判定這一步是否「安全」。
2. 全部放完後按「開始」。此時才會實際播放三連、消除、重力與後續連鎖；配置階段不會先消除。
3. 同款貓的橫、直、兩種斜線連續 3 隻以上會消除。
4. 沒有生命、不扣生命。完整配置結算後仍有貓咪時，只清空本次配置重新試。
5. 不能接著錯誤半盤遊玩，也不能用廣告復原錯誤盤。
6. 一次撤銷與一次提示是關內資源；提示不自動放置，也不宣稱只有一個答案。

## 廣告節奏

每五次遊玩操作顯示一次插頁廣告。遊玩操作包含從首頁或選關開始一關、前往下一關，以及在關卡內點擊「重新開始本關」；計數會保存在瀏覽器本機，重新開啟 App 不會自動歸零。廣告由 gateway 統一控制，測試 gateway 至少維持五秒；正式廣告 SDK 接入後，必須等待供應商回報關閉或失敗，不能用自製倒數提前關閉。廣告不會復原錯誤盤，也不會發放貓幣或其他獎勵。

## 卡片上方的本關條件

托盤卡片上方會顯示本關作者解法的「條件摘要」：橫連、直連、斜連的數量、實際清除格數、落下波數，以及發生 8 向合併時的最大群組格數。介面只顯示大於 0 的條件，不顯示內部消除群數；這些數字由正式順序消除引擎計算，不是另一套判定器。方向與數量使用短符號，例如 `━×4`、`┃×2`、`╱×1`。

條件摘要是讀盤提示，不是唯一答案鎖。玩家只要完成任何能清空盤面的配置都算正確；若橫線與直線交叉，交叉格只計入一次群組數量與清除格數。

## 點擊與消除判定順序

```text
點擊一個合法空格
→ 只檢查座標、空格與托盤順序
   └─ 合法 → 接受放置；不合法 → 拒絕且不改變配置
配置全部完成
→ 按開始
→ 找三連以上的消除群
→ 第一組依放置順序消除一群
→ 只讓失去支撐的上方堆疊下落
→ 落下形成新群？先清完這段連鎖
→ 再回頭處理原本尚未處理的群組
→ 清空：過關；仍有貓：重置本次配置
```

## 順序消除規則

同一波若有多個消除群，第一組找出每個群組中最小的放置數字，數字最小的群組先消除。相同類型、已參與連線且以 8 個方向相連的格子視為同一群；橫線、直線與斜線交叉不拆開。消除後執行局部重力，再重新找下一波；因落下形成的群組必須先全部清完，之後才回到清除前已存在的其他群組。若群組只包含原始盤面貓咪，依固定的上到下、左到右位置處理。

群組數量使用聯集，不使用「每條線各算 3 格」的加總：

```text
群組清除格數 = 所有有效連線格子的聯集
待放貓數 = 關卡總貓數 - 固定盤面貓數
```

## 不算錯誤的行為

點到已佔用格、越界或其他不合法位置時，操作被拒絕且不扣生命。合法但不是唯一解、沒有立即三連、或需要先整理才能消除的配置，也不能被介面判成錯誤。提示的 150ms 背景搜尋只服務提示；超時、失敗或沒有找到建議位置，都不改變放置合法性。

## 關卡邊界

第 25 關完成後顯示主線完成並回到選關。第 26 關以後沒有主線資料、按鈕或解鎖邏輯；未來若要增加內容，必須先另立規格與測試，不能沿用未核准的舊落下關卡。
