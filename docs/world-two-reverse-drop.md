「依賴」由實際 resolver 回放計算：後一波的消除組在前一波消除前尚未完整成形，經掉落後才出現。連續依賴不包含起手那一波，因此 4 次連續依賴至少對應 5 波相接的消除。它是作者路線的設計驗收，不限制玩家使用其他完整解法。

作者工具 `scripts/levels/authorWorldTwo.ts` 以固定亂數種子修改原始布局，驗證無開場自消、作者解全清、唯一盤面輪廓、難度評分 62–80、相鄰評分差不超過 9，以及既有替代解檢查。工具保留目前 JSON 中已合格的關卡，其餘從 Git commit `95e60271fc53398070fc62dcb4e3ab546170c825` 的原始配置搜尋；工具只在 30 關全數通過後寫入 JSON，執行時不會改 manifest 版本。

自動驗證能保證作者解具有掉落依賴，不能保證玩家不會找到更直接的替代解。真人試玩仍需觀察倒推是否容易辨認、提示是否足夠，以及後段的思考負擔。

發布沿用 Cloudflare Pages `meowbox` 的簽名 JSON 管道，保留 RSA-PSS 金鑰。App 啟動時取得新版內容；既有關卡 ID 與進度保持相容。
