# 遊戲底部橫幅廣告

遊戲不再顯示「開始救援」按鈕。所有待放貓咪放入有效格子後，自動開始救援並鎖定操作；最後一隻由提示放置時也適用。未放完仍可使用撤銷。

底部保留 50 邏輯像素的廣告區。原生 AdMob 使用固定 `BANNER`（320 × 50）與 `BOTTOM_CENTER`；iOS SDK 將廣告放在安全區內。375 × 667 的 SE 網頁檢查保持原棋盤和按鈕大小，操作區底部約 586，廣告預覽位於 609–659。

開發網頁只顯示「廣告預覽」，不會請求或產生 AdMob 收益。正式網頁不顯示假廣告。暫停、教學、結算、獎勵廣告確認和設定頁會隱藏原生橫幅；返回遊戲後恢復。離開遊戲會移除橫幅，並處理尚未完成的原生載入。

## iOS 發布設定

- 沿用現有 AdMob SDK、初始化與同意授權流程。
- 新增 `VITE_ADMOB_BANNER_ID`，填入這個 App 的 Banner 廣告單元 ID。
- `VITE_ADMOB_TESTING=true` 使用 Google 測試單元。測試廣告不產生收益。
- 正式版本需要 `VITE_ADMOB_TESTING=false` 與有效 Banner ID；缺少 ID 時不請求正式廣告。
- 現有初始化仍需 App、插頁、獎勵廣告設定完整。
- 更新原生 App 前須重新建置、同步 Capacitor，並在 iPhone 真機驗證同意授權、廣告載入、安全區和頁面切換，再提交 App Store 新版本。

本次完成網頁版面、程式測試和建置；原生真機投放尚未驗證，也未部署或送審。
