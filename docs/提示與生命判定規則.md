# MeowBox｜提示與無生命判定規則

版本：2026-09-23。本檔名沿用歷史路徑，內容已統一為目前 1–30 關規則；完整章節與引擎對照請看 [1–25 關卡設計規格](./1-25關卡設計規格.md)。

## 核心原則

- 1–30 關沒有生命值、不扣生命。遊戲不會因為一次合法放置被判成「死路」而處罰玩家。
- 放置合法性只檢查棋盤界線、格子是否為空、托盤是否依序取用；配置階段不做消除、重力或可解性攔截。
- 合法但沒有立即連線、不是作者路線、或需要先清除支撐才能完成，都可以保留配置。
- 全部放完才開始正式結算；若結算後仍有貓咪，清空本次配置並回到重新安排，不保留半盤。

## 正式狀態機

```text
editing
  ├─ 合法放置 → 保留配置
  ├─ 不合法操作 → 拒絕且狀態不變
  └─ 全部托盤貓已放置 + 開始
       └─ running：逐群消除、支撐落下、重新找群
            ├─ remaining = 0 → completed
            └─ remaining > 0 → editing（清空本次配置）
```

## 結算順序

1. 同款貓在橫、直或兩種斜線上連續 3 隻以上，標記有效連線格。
2. 同色有效連線格以 8 向相連時合併為同一群；交叉格只算一次。
3. 第一組依群組內最小放置數字選出，一次只消除一群；全為固定貓時用上到下、左到右作固定平手順序。
4. 清除後只讓直接失去支撐、且中間沒有空洞的上方連續堆疊落下。
5. 落下造成的新群，或因落下而移動後形成的群，都是目前連鎖；連鎖群必須全部清完，才可回到清除前已存在的其他群組。
6. 每一波重新計算，不使用隨機群組順序；所有清除與落下結果都必須可由 frame 重播。

## 150ms 提示搜尋

提示按鈕會把安全位置搜尋送到背景 worker，等待上限為 150ms。這個搜尋只服務提示：

| 情況 | 遊戲行為 |
| --- | --- |
| 找到已驗證可接續的位置 | 顯示一個建議位置，不能宣稱唯一正解 |
| 超過 150ms | 不顯示本次結果，不拒絕任何合法放置 |
| worker 不可用或搜尋錯誤 | 不顯示本次結果，不代表關卡無解 |
| 玩家一般放置 | 不等待、不呼叫提示搜尋，只做本地操作合法性檢查 |

`canCompletePlanning` 和同步搜尋可以用於離線關卡驗證、作者路線與測試，但不能成為配置階段的錯誤判定器。提示使用量每關一次；搜尋失敗不應消耗提示，也不應修改配置。

## 撤銷與重置

每次配置嘗試可撤銷最新一隻托盤貓一次。結算失敗時，配置、選取、結算 frame 與本次撤銷狀態全部重置；不扣生命、不顯示生命耗盡畫面、不提供半盤廣告復原。整關重新開始才重置提示與其他關內資源。
