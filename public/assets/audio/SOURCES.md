# Meow Line audio sources

These files were downloaded for the Meow Line prototype from Pixabay pages marked
“Free for use under the Pixabay Content License”. Keep this note with the
assets if they are moved to another repository.

- `andressamd-pop-click-576326.mp3` — user-provided download; filename identifies the Pixabay contributor and asset id. Used for button and cat-control feedback. The original source page and license should be retained with the download if the asset is redistributed.
- `geoffharvey-excuse-me-cat-150613.mp3` — user-provided download; filename identifies the Pixabay contributor and asset id. Used as the configured background track. The original source page and license should be retained with the download if the asset is redistributed.
- `gameClear.wav` — supplied by the user; source and license information were not provided. Used for a successful level result.
- `game-over.wav` — supplied by the user; source and license information were not provided. Used for a failed level result.
- `combo-bubble-01-original.wav` and `combo-bubble-02-up2.wav` — locally rendered pitch variants derived from the user-provided `mixkit-soap-bubble-sound-2925.wav` source for combo-audio audition.
- `combo-bubble-tone-02-bright.wav`, `combo-bubble-tone-03-crisp.wav`, and `combo-bubble-tone-04-sparkle.wav` — locally rendered fixed-pitch timbre variants derived from the same source. `combo-bubble-tone-preview.wav` is the sequential listening reel. Confirm the original Mixkit source page and license before redistributing these derivatives.
